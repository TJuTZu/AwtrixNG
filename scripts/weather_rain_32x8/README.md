[`weather_rain_32x8`](scripts/weather_rain_32x8/) 
Weather app showing temperature, humidity and rain/snow, each with a colour-coded 15-hour forecast row, plus moon phase. Each value can be switched on/off in the Apps tab.

## Installing a script

1. Open the AWTRIX NG web interface and go to the **Apps** tab.
2. Upload the `.ax` file from the script's folder.
3. Upload the icons the script needs (listed in the script's own README).
4. Press the gear button on the script's row to set latitude/longitude and the on/off options.

## Requirements

- AWTRIX NG firmware `1.0.10-dev` or newer (script settings form)
- Wi-Fi with access to `api.open-meteo.com`
