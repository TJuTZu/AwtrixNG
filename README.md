# AwtrixNG
AwrrixNG playground

Experiments and scripts for [AWTRIX NG](https://blueforcer.github.io/awtrix-ng/) (Ulanzi TC001 and TC002 matrix).

## Scripts

| Script | Description |
| --- | --- |
| [`weather_rain_32x8`](scripts/weather_rain_32x8/) | Weather app showing temperature, humidity and rain/snow, each with a colour-coded 15-hour forecast row, plus moon phase. Each value can be switched on/off in the Apps tab. |
